# SIM LOD — how often a FAR brood re-steers. Paired with the camera pitch   @tab Horde
# NOT a taste dial. Stride cheapens the dominant sim pass by re-steering distant brood only
# every Nth frame; NearRadius is the correctness boundary that says who is safe to cheapen.
# The pairing is the constraint, not either number alone: a shallower camera sees FURTHER
# down-field, so every degree of pitch you give back has to be paid for here or the LOD
# starts striding units the player can plainly watch stutter.
# Raised 2200 -> 4500 on 2026-07-28 with the pinned eye-level shot (Cam.Pitch -8.2). At -55
# the camera saw ~1650uu of ground and 2200 covered it with margin. At -8.2 it looks very
# nearly ALONG the ground: a body at 5000uu is still ~18px tall at Fov 45.6 on a 1920 view,
# and the brood spawn ring is at 2500-4000uu (BroodSpawnRadiusMin/Max) — so the ENTIRE
# incoming wave used to spawn outside the boundary, fully visible, striding.
# 4500 clears BroodSpawnRadiusMax 4000 with margin. It is not free: far more bodies now count
# as "near" and steer every frame, so the 34k entity ceiling measured at 2200 no longer holds
# and wants re-measuring with -SwarmBench. Lower it only alongside a steeper Cam.Pitch.
# ============================================================
Swarm.SimLOD.NearRadius 4500   ; [500..8000] distance from the bearer, uu, inside which a brood
                               ; always steers at full rate regardless of Stride. Must cover
                               ; everything the camera can actually show resolving
Swarm.SimLOD.Stride 4          ; [1..8] a FAR brood does its two grid queries on one frame in N.
                               ; 1 = off. Measured 2026-07-28 at NearRadius 1600: -32% frame time
                               ; at 20,000 entities. Set 1 first when diagnosing whether a stutter
                               ; on screen is this or something else

# While Emberkeep.Cam.Scale is 1 (as shipped) THIS section, not the GAME CAMERA block above,

                                      ; how much retinue is left. Was 1.
                                      ; 1 = the shot scales with your army and OVERRIDES
                                      ; Cam.Ortho/OrthoWidth/Fov/Dist/Pitch. Everything below is
                                      ; INERT while this is 0 — kept, not deleted, because the
                                      ; feature is sound and only deferred

# --- the FULL-ARMY end of the shot (scalar 1: you command a mass) ---
Emberkeep.Cam.ScaleWidthFull 2400     ; [400..8000] view width uu at full army — the zoom dial
                                      ; that replaces Cam.OrthoWidth while Scale is on
Emberkeep.Cam.ScalePitchFull -55      ; [-90..-5] pitch at full army. -90 = the old straight-down
                                      ; map; -55 = tilted so the arena reads as ground you look
                                      ; ACROSS. TIED TO Swarm.SimLOD.NearRadius — shallower sees
                                      ; further down-field, so lower this and raise NearRadius or
                                      ; the LOD strides units that are on screen
Emberkeep.Cam.ScaleDistFull 1200      ; [200..6000] camera distance back along the view axis at
                                      ; full army. Under ortho this moves the clip planes, not the
                                      ; zoom — ScaleWidthFull is the zoom

# --- the ALONE end (scalar 0: the retinue is gone and you are a man) ---
Emberkeep.Cam.ScaleWidthAlone 700     ; [200..4000] view width uu with nobody left
Emberkeep.Cam.ScalePitchAlone -22     ; [-90..-5] pitch with nobody left — shallow enough to read
                                      ; as standing behind a person, not looking down at a token
Emberkeep.Cam.ScaleDistAlone 420      ; [100..3000] distance with nobody left; short enough that
                                      ; perspective actually bites
Emberkeep.Cam.ScaleSwapAt 0.5         ; [0..1] (owner-tuned, src 0.35) army scalar below which the
                                      ; projection HARD-swaps ortho to perspective. You cannot lerp
                                      ; one matrix into the other, but the FOV is solved from the
                                      ; same framing width, so only parallax changes across the
                                      ; cut. 0 = stay orthographic for the whole run

# --- the driver: how "how much army" is measured ---
Emberkeep.Cam.ScaleRetinueWeight 10   ; [0..50] pull of one live soldier on the scalar. Heavily
                                      ; outweighs the brood on purpose — YOUR attrition is the shot
Emberkeep.Cam.ScaleBroodWeight 0.25   ; [0..5] pull of one live brood. Small but non-zero, so being
                                      ; swarmed holds the shot a little wider
Emberkeep.Cam.ScaleBodies 1200        ; [100..6000] WEIGHTED total at which the scalar pins to 1.
                                      ; = RetinueCap(120) * RetinueWeight(10), so a full retinue
                                      ; ALONE reaches the wide end. Raise it above that and the
                                      ; wide shot becomes unreachable in normal play
Emberkeep.Cam.ScaleCurve 1            ; [0.2..4] shaping exponent on the 0-1 scalar. 1 = linear;
                                      ; >1 holds the wide shot longer then collapses late; <1
                                      ; descends early and eases out

# --- how the move FEELS (none of these change where the camera ends up) ---
Emberkeep.Cam.ScaleStiffness 3        ; [0..20] spring natural frequency rad/s. Eases INTO the move,

                                      ; 0 disables the spring and falls back to ScaleLerp
Emberkeep.Cam.ScaleDamping 1          ; [0.2..3] spring damping RATIO. 1 = critically damped, no
                                      ; overshoot. Below 1 rebounds past the framing, which reads
                                      ; as a mistake rather than as weight

Emberkeep.Cam.ScaleRatchet 0          ; 1 = one-way: the camera descends as the army dies and never
                                      ; rises again, even if a breather refills the retinue.
