# RawArt/Renders/

Landing zone for **every** PixelLab MCP creation — characters, portraits, tiles, tilesets, objects, UI assets, fonts. See `docs/PIXELLAB-MCP.md` → "Retention rule."

Rule: nothing gets deleted here, including rejects and rough drafts. Once a result is chosen, move it out to its proper home (`RawArt/Portraits/`, `docs/art/`, engine content folders, etc.). Anything still sitting in this folder is undecided — leave it alone.
