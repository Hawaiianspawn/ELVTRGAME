Army composition — four directions

Every option keeps the bearer + flame as the centre and the locked Demichrome palette. They differ on one axis: how literally the roster maps to the battlefield — from a ceremonial readout to a live tactical map.

1Flanking Wingsceremonial · symmetric
The host arrays to either side of the bearer, each wing a stack of squads leaning inward — the deity flanked by the congregation.
Best reads as fantasy; symmetric; scales down a wingWatch needs a left/right rule
2Radial Musterthematic · encircling
Squads ring the bearer like the light itself radiating outward — the point-light fantasy made into the HUD. Order around the circle can mirror the real ring.
Best most on-theme; no wasted cornersWatch tight for 8+ squads; labels crowd
3Command Railutility · dense
One clean roster of strength bars docked to a side, the cam centre-stage beside it. The RTS-standard read: scan the bars, click to command.
Best densest; scrolls to any count; clickableWatch least distinctive; one-sided
4Formation Maptactical · spatial
Squads sit where they actually are around the hero — composition is position. Blob size = headcount, colour = health. Doubles as a minimap.
Best ties UI to the sim; real tacticsWatch headcount harder to read exactly
How to choose: pick the one whose strength matches what the moment-to-moment game is about.
