The Wave Board

One five-row instrument, three states, over the actual live scene it interrupts — not a separate screen. The board docks in the central well of the collapsed combat HUD; the company meter and stance indicator stay visible underneath it through an Ink scrim, because the player is reading a report about the army they're still looking at.

Chrome (card frame, corner rosettes) is placeholder geometry standing in for the pixel-art-director's Sampler Frame plate set, reused at a smaller size — this page previews layout, palette, and state, not finished art. Same token system as ui-aesthetic-menu-and-wave.html — no second visual language.

Reading this board

No colour or icon splits kinds

Aggregate rows carry a ×N suffix in Iron; individuals carry a small role tag instead. The text says what it is — nothing else does.

A real lead, or no Ember at all

Rank 1 only jumps to Ember when its count strictly beats rank 2's. A tie at the top — a realistic early wave — leaves the whole board Iron/Parchment, on purpose.

† outlives the entity

A fallen individual's row is a snapshot, not a live read — the soldier is gone, the number it earned isn't. A wiped squad needs no snapshot at all: its counter never lived on its members.
