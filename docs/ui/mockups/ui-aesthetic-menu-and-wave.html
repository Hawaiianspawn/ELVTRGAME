Full colour, four roles, one reserved red

Two surfaces from the same token system, side by side so the palette and the density rules can be judged against each other rather than in isolation: the pause/muster panel (structure-heavy, low density) and the end-of-wave board (five ranked rows, high density, mixed row kinds).

Chrome shown here (frame, corners, medallion) is placeholder geometry standing in for the pixel-art-director's Sampler Frame plate set — this page is a palette/density/state preview, not finished art. Body/label type is a system monospace stand-in; the real pixel face is still an open pick (§3).
