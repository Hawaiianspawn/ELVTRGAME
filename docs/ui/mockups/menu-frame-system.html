The menu is summoned, not booted into

The game boots straight into Deploying — there is no title screen. This is what pressing Start looks like mid-fight: the run hard-pauses, the Sampler Frame takes the screen back from the battle, and the same Muster well built for the old main-menu flow reappears as an overlay. Dismiss returns to exactly where the wave left off.

Chrome (frame plate, medallion, corner brackets) is placeholder geometry, not final pixel art — this previews structure, palette, and the pause behaviour, not finished art. The scattered dots behind the frame stand in for the frozen swarm; they are not a battle render.

What summon does, phase by phase

PhaseSummon behaviour
Deploying Opens same as any other phase. Low stakes — the formation is still settling — but the sim still hard-pauses for consistency; no special case.
WaveActive The case above. Hard pause (single-player — no other player's clock to protect), frame takes the full screen, battle freezes exactly where it stood. Dismiss resumes mid-swing.
Breather Same hard pause, and it also freezes PhaseTimer — reviewing squads in Muster must never burn down the breather clock and force an unwanted wave start.
Won / Lost Summon still opens Muster/Settings (still useful for Quit or reviewing the roster), but it is not how results are read — that's task-116's end-of-wave board, a separate screen shown automatically, not reached through this summon.
