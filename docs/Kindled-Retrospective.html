Project Retrospective

Aaron Low · 12 July – 1 September 2026 · token figures from the Kindled Pipeline Ledger

Three games, one pipeline

Kindled shipped as a Godot 4.7 browser game, but it spent most of its life as an Unreal 5 Mass Entity swarm. The project's real through-line was never the engine — it was the AI pipeline (PixelLab art chain, agent crew, sim harness, approval ledgers), which survived two hard pivots that the engine code did not.

What the tokens actually bought

Total compute at API list price: $1,809.35 across 7,935 model calls and 94 sessions — but only 5.4M of the 1.4B billed tokens were output. The other 1.38B were the orchestrator re-reading its own growing context, served from cache at 0.1× (~$10,900 saved). Average across the project: $1.73 of list-price compute per human prompt — and roughly $150 of actual cash, thanks to flat subscriptions.

/host — turning one orchestrator into a studio

By late July the working style had a bottleneck: one long session doing everything. The answer was /host (Jul 26), a custom skill that became the front door for all new work: hand it a feature list, and it splits the ask into lock-checked task files, asks a scheduling agent which tasks are independent, runs the batch past a reviewer agent instead of interrupting the owner, then dispatches the independent tasks to parallel teammates — capped at one question and one permission prompt per batch. The ledger vindicates the design: the delegated lane produced a large share of the shipped artifacts for $208 (11.5% of spend), while the single-threaded orchestrator context cost $1,601. The retrospective lesson is that /host arrived six weeks in; delegation-first from day one is the architecture change named in the audit.

The character selection screen, before and after

No single screen shows the pipeline's effect better. Both screenshots are the same scene, the same GDScript flow, three days of PixelLab production apart: the title frame, hero card, medallion portrait, nameplate and dungeon backdrop are all pipeline output — generated from request specs, quantized to palette, landed by godot_pack.py / ui_land.py with no manual reformatting. Seven heroes sit behind that card ([H] cycles them), each with a 64px bust from the portrait bucket (~175 generations, $0.88).

What we'd keep, what we'd change

  • Keep: measuring before believing. The Unreal entity ceiling, silhouette variety, and every cost claim in the audit came from harnesses, not eyeballs. The pivots were cheap because the evidence was already in hand.
  • Keep: engine-agnostic pipeline output. PNG strips + JSON survived Unreal → Godot untouched. The week the engine changed, the art pipeline didn't lose a day.
  • Keep: human taste gates. One approval per anchor frame was the cheapest quality control in the project — everything downstream inherited an approved look.
  • Change: delegate from day one. 88.5% of token spend was orchestrator context re-reads. /host proved thin-router + parallel teammates works; it should have been the starting architecture, not the mid-project fix.
  • Change: pivot to the deliverable's platform sooner. The web-playable gate was known from the start; the Godot pivot waited until day 37 of 52.
