Integration Breakdown

Target Game Engine: Godot 4.7, HTML5 export (an earlier Unreal 5 / Mass Entity prototype of the same pipeline lives in the same repo).
Automated Flow Description: An art-director agent writes a schema-validated request JSON; pixelpipe drives the PixelLab MCP through anchor → palette quantize → 8-way rotate → animate, recording provenance per generation. Then:
request.json → pixelpipe (PixelLab MCP) → RawArt/Renders/<id>/ → godot_pack.py → godot/assets/sprites/<unit>.png → Godot auto-import → Battle scene

godot_pack.py reads godot/data/roster.json, resolves each unit through the owner-approval ledger, and writes 8-direction sprite strips directly into the Godot project in the engine's expected cell layout; Godot's importer picks them up with no hand step, and the battle scene binds them to stat rows in units.json. Audio lands the same way via sfx.py. Nothing in the shipped build was manually reformatted.

01 Pipeline Production & Functionality

What did the pipeline produce? Everything visible and audible in the playable build: 68 packed sprite strips (7 heroes, allies, 8 enemy types, the necromancer boss, ~30 castle props), 68 animation clips, 7 hero portraits, 3 pixel fonts, 23 UI textures (buttons, meters, chips, win/lose cards, cursor), the title background, 10 VFX, 39 normalized sound cues, and the JSON stat/wave tables (19 units) that the committed combat-sim harness balanced.
What manual steps remain? Three: (1) the anchor-approval gate — a human says yes to one frame before rotation/animation inherit it; (2) keep/deny verdicts on generated variants via the roster approval page; (3) the itch.io deploy is a manually invoked script (release.ps1 + butler push).
What would it take to eliminate them? Steps 1–2: auto-verdict from the already-measured silhouette metrics (aspect, solidity, asymmetry thresholds in silhouette_report.py) instead of human taste — technically trivial, deliberately kept human because taste gates were the cheapest quality control in the project. Step 3: a CI job running headless export + butler on merge; one afternoon of work.

02 Architectural Reflection

Decision I would change: Running one long-lived orchestrator session as the pipeline's brain. The ledger shows 88.5% of all token spend ($1,601 of $1,809 at list) went to the orchestrator re-reading its own growing context on every tool call — 1.08B cache-read tokens — while the delegated agents that produced most of the actual artifacts cost $208.
Specific alternative: Delegation-first: a thin router orchestrator that holds only the task list and verdicts, with every file read, generation loop, and engine import in short-lived subagent contexts that return one-paragraph summaries. Measured against this project's own split, that caps the quadratic context growth and would have cut the token bill by roughly 5×.

03 Cost Analysis

Total Actual Run Cost: $1,831.29 at provider list prices ($1,809.35 LLM tokens + $21.94 PixelLab), computed from 103 session transcripts and balance logs, Jul 12 – Sep 1. Actual cash: flat subscriptions (~$50/mo art + Claude plan, two billing months).
Most Expensive Pipeline Step: Claude Fable 5 cache reads — $1,075.76 for 1.08B tokens of orchestrator context re-reading. One line item worth more than all output tokens ever generated ($224) and 49× the entire art budget.
Solo/Small-Team Sustainability: Sustainable — but only because of subscription pricing and cache discipline. The full shipped art set cost $21.94 (44% of one month's PixelLab allowance). At raw API prices this working style would run ~$900/mo; uncached, ~$6,200/mo. The two levers that make it viable — flat-rate LLM access and 0.1× cache reads — are structural, not luck.

04 Mid-Project Cost-Reduction Change

Strategy / prompting — beforeAfter
Every tool call re-bills full context as fresh input; PixelLab images sent as inline base64 (~30% of calls truncated in transit and re-bought). 1-hour prompt caching on all sessions + URL-based image transport; VFX and repeat animation moved to zero-credit procedural code and animate_image on already-paid frames.
Token / API cost — beforeAfter
~$12,484 (1.4B input-side tokens at base rates); art re-buy tax ~30%. $1,809.35 actual — an 85.5% reduction; truncation failures zero; 53 production clips for ~$0.35.
